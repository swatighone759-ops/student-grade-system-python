# Student Grade System 🎓

This is a beginner-friendly Python project that calculates student grades based on marks and percentage.

## Features
- Takes student marks as input
- Calculates total and percentage
- Assigns grades automatically
- Displays result in a simple format

## Technologies Used
- Python

## Concepts Used
- Variables
- Input/Output
- If-Else Statements
- Arithmetic Operations

## Example Output

Enter marks: 85

Percentage: 85%
Grade: A
